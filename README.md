# Tormaster — Usinagem e Projetos

Website institucional desenvolvido para a **Tormaster — Usinagem e Projetos**, com foco na apresentação dos serviços, informações institucionais, portfólio de projetos e canais de contato.

O projeto consiste em uma aplicação web estática, desenvolvida com tecnologias nativas, sem dependências de frameworks ou bibliotecas externas obrigatórias.

## 1. Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript (Vanilla):** funcionalidades e comportamento dinâmico da interface.
- **PDF:** documento complementar de apresentação institucional.
